**ZENKAI** es una app de escritorio que programa contigo usando modelos de IA que corren **en tu propia PC** (vía Ollama, LM Studio, Jan o llama.cpp) o en la nube gratuita. Sin depender de servicios de pago.

## Qué incluye

- **Programación asistida** con herramientas propias (edición, git, memoria persistente, RAG para estudiar carpetas).
- **Generación de imágenes** gratis integrada.
- **Modo sin permisos** (autónomo) opcional.
- **Motores locales**: Ollama, LM Studio, Jan, llama.cpp. Auto-instala Ollama en el primer arranque.
- **Modelos en la nube gratis** además de los locales.
- **Acceso por licencia**: solo entra quien tenga credencial válida.

## Instalación

Descarga el instalador desde la sección **[Releases](../../releases)** y ejecútalo:

```
zenkai-desktop-win-x64.exe
```

En el primer arranque, ZENKAI instala automáticamente lo necesario (Ollama) y descarga el modelo por defecto.

## Acceso

ZENKAI requiere credencial para iniciar. Las credenciales se generan desde el panel de administración (`herramientas/panel-credenciales.html`) y se distribuyen de forma privada. Sin credencial válida, la app no inicia.
