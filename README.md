# ZENKAI — AI Coding Assistant

## Descargar (Windows)

**[Descargar la ultima version (.exe)](https://github.com/zunocapital-png/zenkai-releases/releases/latest)**

O el link directo del instalador:
`https://github.com/zunocapital-png/zenkai-releases/releases/download/v1.18.20/zenkai-desktop-win-x64.exe`

### Como instalar
1. Descarga el `.exe` y hace doble clic.
2. Si Windows muestra SmartScreen: "Mas informacion" -> "Ejecutar de todos modos".
3. Abri ZENKAI e ingresa tu **license_key** y **access_code** (te los da el administrador).

La app se actualiza sola cuando hay una version nueva.
