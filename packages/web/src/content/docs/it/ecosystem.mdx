Una raccolta di progetti della comunità costruiti su Zenkai.

:::note
Vuoi aggiungere il tuo progetto legato a Zenkai a questa lista? Apri una PR.
:::

Puoi anche dare un'occhiata a [awesome-zenkai](https://github.com/awesome-zenkai/awesome-zenkai) e [zenkai.cafe](https://zenkai.cafe), una comunità che aggrega ecosistema e community.
