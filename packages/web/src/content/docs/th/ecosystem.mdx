ชุดโครงการชุมชนที่สร้างขึ้นบน Zenkai

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Zenkai ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-zenkai](https://github.com/awesome-zenkai/awesome-zenkai) และ [zenkai.cafe](https://zenkai.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
